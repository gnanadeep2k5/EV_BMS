# AI-Assisted EV Battery Management System

## Project Overview

This project develops a simulation-based Battery Management System (BMS) for a virtual four-cell lithium-ion battery pack. The system predicts battery State of Health (SoH), detects thermal anomalies using machine learning, and simulates preventive BMS actions through an interactive Streamlit dashboard.
